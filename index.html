    如何启用本地存储

    开启后 VIP 和余额才能长期保存

    • Chrome / Edge：点地址栏左侧的锁🔒图标 → 网站设置 → Cookie 和网站数据 → 改成「允许」→ 刷新页面
    • 或直接访问 chrome://settings/content/cookies，确认「允许网站保存和读取 Cookie 数据」已开启
    • 如果是双击 HTML 打开的：Chrome 对 file:// 有限制，建议用 python -m http.server 8000 起个本地服务
    • Firefox：检查设置里是否开了「从不记住历史记录」
    • 无痕/隐私模式：换普通窗口打开
